# Riff App Landing Page

Marketing landing page for Riff App — Shazam for guitarists.

## Stack

- React
- Vite
- Firebase Hosting site: `riff-app-landing-page`
- Firebase project: `riff-app-d747b`

## Local development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy

```bash
npm run deploy
```

Production URL: https://riff-app-landing-page.web.app
